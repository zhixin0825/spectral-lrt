# 全文检查与实质修订（2026-10-10）

本轮接续“全面检查修订”的最新要求：密度 `p = Ω(log n/n)`、允许不等 degree，不固定 `(n/log n)P`，并完成任意固定 K 的算法保证。这里统一记 `p = max_ab P_ab`。当前稿件已用完整 Bernoulli score 和确定性 repeated replacement 给出对应证明。本文记录源码、实现、实验、主引用和当前 PDF 的审计；本次记号同步后已重新编译并逐页核验。早期版本的记录保留在 Git 历史。

## 一、结论和实际条件

主算法使用原始 adjacency 的 top-|lambda| K 个 eigenpairs，此后只使用谱重构。实际概率矩阵 P 对称。对于任意固定 K，满足下列固定正常数条件：

- 每个社区 `n_a >= pi0*n`；
- 所有 a,b 均有 `P_ab >= kappa*p`；
- `sigma_min(P) >= kappa*p`；
- `p <= 1-eta`；
- `p = Ω(log n/n)`。

算法 floor 系数需满足 `0<c0<min(kappa,eta,1)/8`。不要求 `P/p` 或社区比例收敛，也不要求 expected degree 等于或至多为 order log n。对于类别 a 的节点，期望 degree 是 `sum_b(n_b-1{a=b})P_ab`，在统一概率界下为 `Θ(np)`，可以因社区而异。因此密度条件给出每个节点的 `Ω(log n)` 期望 degree 下界。

完整 Algorithm 1 的结论为 `E Mis <= exp(-(1+o(1)) I_n)`；`liminf I_n/log n>1` 时 exact recovery。I_n 使用排除自环后的精确 product-Bernoulli Chernoff information。“Nearly optimal”只表示 leading exponent，不声称 Zhou–Li 的精细乘法 rate 或新的全局 minimax 下界。

## 三、一般 K 证明的独立审查

人口层面的关键是 K 个真 profiles 和 K 个拟合 profiles。将每个真 profile 分配到最近中心；若有未被选中的中心即可删除，否则该对应是双射。插入损失最大社区的真 profile，在不增加其他社区损失的情况下去掉至少 `G_*/K`。

统一平均谱误差给出每个真社区可用的 observed candidate，并同时控制所有可能 fitted lists 的 `G-G_*`。全部删除位置的候选扫描找到至少同样好的 empirical replacement。Uniform trial weights、`G<=F<=G+n log K` 的相应界、exact EM monotonicity 和按同一目标选优合成

`F_(t+1) <= (1-1/K)F_t + B a_n n^2 p + n log K`。

`ceil(log n)` 轮后得到 deterministic `F<=xi_n n^2 p`，`xi_n -> 0`。审查收紧了两个量词/停机表述：

1. Low-loss lemma 明确对每个 deterministic xi_n，统一覆盖 `F<=xi_n n^2 p` 的所有 fits；没有把各自 little-o 的所有序列错误视作共享一个速率。
2. 无改进的一整轮直接给 `F_t<=K(B a_n n^2 p+n log K)=o(n^2 p)`，所以早停有效，不必假定未来使用同样的 fitting budget。

强凸性、K 对 K 的一一匹配以及 `F_i=sum_k R_ik D_ik+KL(R_i||pi)` 给出弱 responsibilities。该证明允许零权重；最后强制一次 profile/weight M-step 才完成 score accuracy。独立复核未发现这条主证明链的实质缺口。

## 四、一般密度和局部 EM 的独立审查

直接重查 [Bandeira–van Handel](https://arxiv.org/pdf/1408.6185) Corollary 3.12、Remark 3.13，以及 [AFWZ](https://arxiv.org/pdf/1709.09565) Theorem 2.1、Lemma 7。Centered independent bounded upper entries 和 Bernoulli row concentration 均支持对任意固定 H 的指数置信度；这里不隐藏使用 `n p=O(log n)`。

正负信号 eigenspaces 分别处理，真实均值保留 `-diag(P_aa)`。重构恒等式把 first-order eigenspace bound 转为统一 row l1 误差。平均 block-count deviation 使用 bounded differences；所有事件合并仍有 `C_H exp(-H n p)` 概率界。

随机双侧 floor 的 Chernoff argument 使用确定性 `epsilon_+=2c0*p`，按 logit contrast 的符号选择不利 clipping 一侧；每块至多因子2，再对独立 raw block counts 分解，得到 `2^K` 因子。重构 diagonal 只多 `O(p)` offset。

局部拟合在共同 box 内具有统一导数界，M-step profile 误差为 `O((gamma_n+a_n)n p)`。Invariant basin 在同一个 graph event 上同时控制所有后续 finite exact updates；data-dependent stopping 不需要 iteration union bound。已补明 fitted score 包含 log weight，以及 oracle Bayes risk 的 fixed-prior 条件。

## 五、真实反例和全部数值结果

### 有限 stage growing 的严格证书

[population_audit](../../experiments/20261010_general_density/population_audit/) 提供 K=5、逐项正且对称正定的有理矩阵和区间对数证书。每阶段只做一次 M-step 时，growing 的 limiting path 重复覆盖 block 4，合并 blocks 3 和5，误分为 `13/200=0.065`。一轮 deterministic replacement 修复。

这不证明每阶段充分迭代的 growing 失败；同一实例每阶段两次 M-step 成功。它也不是 sampled-graph 失败定理。正文和报告都保留了这些边界。

## 七、仍明确不包含的结论

未声称 growing-only 的 unrestricted general-K 保证、K随n增长、`p = o(log n/n)` 时的完整算法保证、rank条件退化时的通用结论、任意不合适floor的保证、refined multiplicative risk 或新的全局minimax下界。

单次replacement不能由本收缩直接推出o(1)初始化误差；当前定理要求重复轮数或无改进的完整轮次certificate。直接实现的candidate cache仍需要三次量级计算和二次存储。有限样本weak-signal失败和计算优化都是后续研究问题。
